# Expression Calculator

A small command-line calculator written in Python. It reads a simple two-number expression and supports addition, subtraction, multiplication, and division.

## Features

- Accepts expressions such as `10 + 3` or `10+3`
- Supports `+`, `-`, `*`, and `/`
- Checks expression format and numeric input
- Handles division by zero

## Run locally

```bash
python Expressioncalculator.py
```

This project practises string handling, loops, conditionals, exception handling, and arithmetic operations.
